# 路由、导航、标签与显示配置契约

状态：行为已确认，前端尚未实施。返回 [PRD](../prd.md)。依据：前端 Q43、Q47、Q49–63、Q113–145、Q224，整体复查 Q55；[标签历史](../decisions/interview-archive-2026-10-15.md#legacy-9-5)、[路由历史](../decisions/interview-archive-2026-10-15.md#legacy-9-52)。

## 1. 路由与初始化

前端源码定义路由，标题、图标、排序和权限元信息生成菜单；后端提供授权，不把菜单定义改为接口管理。身份／权限恢复后筛选并动态注册业务路由，权限变更及退出时维护增删，懒加载独立保留。

前端新路由默认认证，公开入口显式声明。业务页面必须声明资源操作权限或所有有效账号可访问的例外，遗漏视为配置错误且不放行。实际父子路由累计检查已声明权限；菜单视觉分组与高亮关联不凭空产生授权要求。

普通初始化函数集中编排身份→权限→路由→合法账号所属标签→目标业务页面，Guard 触发或等待。区分未知、未登录、失败、就绪；首次完成前不显示旧业务、标题和猜测的权限路由。网络／5xx 不判为会话失效或无权，初始化失败提供重试和主动进入登录，保留安全站内目标。

初始化并发复用、部分失败清理、精确路由类型和权限表达待验证。认证恢复与跨账号清理遵守 [身份契约](identity.md)。

## 2. 菜单与异常页面

- 单一侧栏＋顶部＋多标签＋内容布局，支持侧栏折叠与品牌配置。顶部设置按钮打开右侧显示偏好抽屉，即时预览。
- 面包屑按实际路由层级，仅有效可访问目标可跳转，不为纯分组伪造页面。菜单搜索只匹配当前语言下有权且可见的菜单名称，不搜索业务数据或自动纳入隐藏动态详情页。
- 菜单允许多个分组同时展开，进入页面展开所属路径；隐藏详情／编辑页显式关联菜单高亮，隐藏不等于无权限，折叠菜单不关闭标签／销毁页面。
- 已登录无页面权限显示无权访问；未知前端路由显示页面不存在。两者保留后台外壳并可回可访问首页，不挂载被拒业务。已知但未注册的无权路由不能误报未知路由。
- 全局异常页不新建或持久化错误标签。详情接口明确记录缺失时原址提示不存在／已删除并可回列表，不继续展示旧记录或允许其操作；不能把全部 API 404 当作记录删除。
- 所有有效登录账号可访问基础首页，只包含欢迎和授权导航；业务统计另行鉴权。权限变化的标签清理见身份契约。

首版只保证桌面，窄屏保留桌面最小宽度并允许整体滚动，不自动要求手机抽屉或单列适配。最小宽度、键盘交互和实际验收视口待方案确定。

## 3. 应用内标签身份与操作

标签是一个浏览器窗口内部的页面切换栏，与多个浏览器窗口共享 Cookie 的模型不同。标签元信息、缓存页面实例和服务器 Query 缓存分别管理。

| 事项 | 规则 |
| --- | --- |
| 标签身份 | 默认路由名＋路径参数；query 不拆新标签，特殊业务可显式定义 |
| 同身份新地址 | 更新目标 query 并激活已有标签 |
| 固定首页 | 最左，不能关闭，确保始终有可访问入口 |
| 关闭当前 | 左邻优先，再右邻，否则首页；关闭非当前不导航 |
| 基础操作 | 刷新当前、关闭当前、关闭其他、关闭全部；固定页除外 |
| 批量关闭 | 先检查所有目标，一次确认；取消则一个也不关，确认期间目标状态变化时重新保证关闭条件成立 |
| 容量 | 默认最多 20 个，可开发配置；到限提示先关闭，不自动淘汰打开标签及已缓存实例 |
| 标签刷新 | 重取当前页登记的查询，保留输入、筛选和分页，不默认销毁重建页面 |

## 4. 页面缓存、关闭保护与恢复

页面默认不缓存，由路由显式开启。关闭释放目标页面实例及本地状态，保留共享 Query 资源；不能把 KeepAlive 实例生命周期与服务器缓存回收混为一谈。

隐藏缓存页默认暂停自身自动查询，业务可显式声明后台需要；切回按新鲜度更新；其他可见 observer 可刷新共享 key，已发读取允许完成。精确释放某个标签实例、查询启用及挂载时序必须验证，不能只使用 KeepAlive 就宣称已完成。

可能丢失业务编辑内容的关闭／导航先确认，登记状态包含业务值差异及尚未形成合法值的非法／未完成输入；普通缓存切换不丢内容时无需确认，搜索草稿不默认算业务编辑。浏览器刷新／关闭依赖原生提示可用边界，不承诺强拦截或自定义文案。详细字段规则只在 [表单契约](form.md) 维护。

标签元信息使用 sessionStorage，只承诺当前浏览器标签会话内恢复；不恢复页面实例、表单草稿或 Query 内存。恢复先检查账号归属、路由和权限，不能将另一账号的工作区带回。存储不可用时降级及精确元信息类型待定义。

启用 URL 同步的页面同时可以缓存，按 Q224 绑定标签身份并在激活前协调地址；完整地址读写与草稿恢复规则以 [DataTable URL 契约](data-table.md#url-sync) 为唯一维护位置。

## 5. 语言、主题与显示偏好

首版简体中文与英语。未显式选语言时跟随浏览器，不支持则简体中文；自动检测结果不存成手选覆盖。主题默认跟随系统，支持浅／深／system，system 保存模式并随系统变化。

只保存用户显式选择字段：用户覆盖 ＞ 项目默认 ＞ 内置默认；显式选择即使恰好等于当前默认也可保留。未选字段随新版本默认更新。显示偏好归浏览器，同源同应用共享，不按账号或设备同步到后端；退出保留。

其他窗口同步合法偏好，防止回写循环；应用命名空间隔离，不夹带授权、业务数据、草稿或标签工作区。保存失败时当前窗口临时生效并提示，不阻断业务，不承诺刷新后仍保存或跨窗口同步。

升级保留合法字段，可明确迁移的迁移，其他回退默认；损坏／未知字段不能直接信任，无变化不强迁移。统一恢复显示默认需确认，只删除本应用显示覆盖，重新跟随浏览器／系统；不清登录、业务、Query、标签或整个站点存储。

具体持久化介质、版本、字段清单与迁移代码待定；研究中出现 localStorage 不等于已锁定该实现。

## 6. 部署配置与业务设置

前端部署配置采用构建时输入；关键配置无效时阻止进入业务并明确报错。公开配置不可存秘密。品牌、路由、模块等开发者配置由源码提供；管理员业务设置首版只提供接入说明，有明确需求后在所属业务实现页面。

## 7. 待验证与验收

验收包含未登录／初始化失败重试／失权／未知路由／缺失记录的不同状态，父子权限累计，安全返回地址，标签关闭邻居选择、批量取消、20 标签上限、账号所属恢复、目标实例释放、隐藏查询与共享缓存、多页面 URL 隔离，以及显示偏好多窗口同步、损坏存储、写入失败、升级和恢复默认的范围。
