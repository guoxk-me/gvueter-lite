# 表单与编辑容器契约

状态：行为已确认；[Phase 2](frontend-phase-2.md) 已实现 SchemaForm 的 input／switch、字段扩展和 FormDialog，并验证相应类型、交互与失败分支。本文其余控件、FormDrawer、远程选项与联动等仍待实现，不能按整份契约宣称完成。返回 [PRD](../prd.md)。依据：前端 Q21、Q24–28、Q146–163、Q196–212，整体复查 Q55；[历史原文](../decisions/interview-archive-2026-10-15.md#legacy-9-82)。

## 1. 默认入口与所有权

公共表单内部创建唯一字段状态，使用 TanStack Form＋Zod。普通新增／编辑使用组合好的 FormDialog／FormDrawer；特殊布局可组合独立表单与通用弹窗／抽屉。页面提供字段、取数／保存函数、打开状态、编辑上下文和资源更新规则；公共组件不依赖具体业务 API。

字段配置只描述字段、控件、校验、布局和联动，不混入业务 URL、列表刷新或保存流程。普通页面不必先创建表单控制对象；内部 composable 是实现组织方式。

## 2. Props、回调与 Emits

下表定义已确认语义。名称是当前设计用名，完整泛型、可选性及扩展属性仍须验证；示例中的 title 不等于已确认全部布局 props。

| 入口 | 所有者与语义 |
| --- | --- |
| open／v-model:open | 页面持有唯一打开状态；容器经关闭保护后通知更新 |
| context | 有类型的新增／编辑上下文；每次打开固定本次快照，任意深层变化不自动重填输入 |
| fields | 强类型字段定义；字段路径、值类型、control 和控件 props 关联 |
| load(context) | 返回同步初始值或 Promise；业务负责获取完整模型，公共层负责加载、重试和初始化 |
| submit(values, context) | 可等待的保存回调；返回明确写入结果，失败抛出错误，不能吞掉失败或未知结果伪装成功 |
| update:open | 遵守关闭协调后通知页面更新打开状态 |
| saved | 明确成功后通知本次 context 和保存结果；页面更新／失效资源，不靠异步事件返回值决定关闭 |

新增由业务明确给默认值，编辑提供完整记录；不静默补 false 等缺失字段。保存回调只承担本次写入，后续列表刷新失败不改报保存失败。可用调用形态（不是完整类型定义）：

```vue
<FormDialog
  v-model:open="isEditorOpen"
  :context="editingContext"
  :fields="userFields"
  :load="loadUserForm"
  :submit="saveUser"
  @saved="handleUserSaved"
/>
```

FormDrawer 使用同一核心契约。普通父级关闭也通过统一 requestClose 协调；子组件不能拦截父级任意销毁。账号变化或权限撤销的强制清理遵守应用身份流程。

## 3. 生命周期

1. 每次打开建立本次上下文、读取初始值并创建编辑快照。仅复用同账号、同记录、完整、新鲜且未失效的详情缓存；默认新鲜期沿用 [Query 契约](http-query.md)。过期／失效／缺失则等待读取，失败不开放提交并提供重试。
2. 编辑快照独立于 Query 缓存；后台详情更新不覆盖正在输入的表单。初始化／回填不触发用户来源的级联清值。
3. 保存先校验，取本次提交快照，等待 submit；期间锁输入、重置和关闭，阻止重复写入。业务禁用与暂时提交锁定分别处理。
4. 明确成功后标记已保存，发 saved 供业务及时更新／失效资源，然后关闭；资源刷新或通知处理异常不应破坏已成功的收尾。
5. 明确失败保留输入与可定位错误；结果未知遵守 [写入未知结果](http-query.md#write-unknown)，允许结束等待并关闭，但关闭重开不能解除相关冲突写保护。
6. 关闭完成才卸载表单，下次打开新建，不默认保存跨次草稿；取消关闭不提前清理。旧读取、写入回调及旧卸载任务不能修改快速重开的新实例。共享 Query 缓存按自身生命周期保留。

## 4. 首批九类控件

| control | 编辑模型 | 清空值 |
| --- | --- | --- |
| input | string | 空字符串 |
| textarea | string | 空字符串 |
| password | string | 空字符串；是否发送由业务决定，不意味着必须改密 |
| number | number 或 null | null；0 有效 |
| select | 单一 string 或 number ID 类型，或 null | null |
| multi-select | 同一种 ID 类型的数组 | 空数组 |
| switch | boolean | false |
| checkbox | boolean，首版不暴露三态 | false |
| date | 有效 YYYY-MM-DD 字符串或 null，不含时间／时区 | null |

公共适配负责底层控件差异。选择 ID 不静默转换数字／字符串，单选空字符串不作为普通合法 ID。数字非法或未完成输入须保留可理解反馈并阻止提交，不能变成 0／null，也不能提交上一次合法值；NaN／Infinity 不可提交。金额精度、超安全整数 ID 使用明确业务类型。

纯日期不经本地午夜 Date → UTC 导致跨日；语言只影响显示。null、空字符串和空数组表示明确清空，字段省略表示不发送；不能统一删除所有空值。API 是否接受清空由业务契约决定。

首版支持列数、字段跨列、分组、说明，以及必填、长度、邮箱和自定义校验。动态字段组、上传、富文本、树选择、日期时间和日期范围按场景扩展；日期范围可由两个纯日期字段表达。

## 5. 字段状态、校验与提交类型

| 状态 | 默认保留值 | 用户输入校验 | 默认提交 |
| --- | --- | --- | --- |
| 隐藏 | 是，重新显示恢复 | 不参与 | 省略 |
| 业务禁用 | 是，重新启用恢复 | 不参与 | 省略 |
| 只读 | 是 | 不参与 | 保留已有值 |
| 提交中临时锁定 | 是 | 本次校验／快照不因锁定改变 | 不剔除已准备字段 |

隐藏／业务禁用允许字段显式覆盖，具体覆盖接口待定。状态变化应清理不再适用的错误和提交阻断，恢复参与后按既定时机校验，不只隐藏提示。后端仍独立检查字段权限及业务规则。

单字段 Zod 规则就近放在字段配置；跨字段规则单独声明依赖与错误目标。只读依赖可参与适用的跨字段约束；隐藏／禁用依赖须明确参与策略，不能一律执行或静默跳过。Zod transform／coerce 不自动视为已改写编辑状态或提交输出。

默认首次失焦或提交时展示输入错误，已有错误随修改更新。修改字段清该字段旧服务端错误，不清其他字段和仍有效的客户端错误；迟到服务端错误必须绑定对应提交和实例。仅在用户提交触发字段校验失败时，按实际显示顺序滚动并聚焦首个可见、可编辑、可聚焦的错误字段；普通输入／失焦不抢焦点，无法聚焦时仍保留错误与兜底提示。

字段路径、值类型和控件 props 强关联；公共 value／更新事件／锁定／错误属性不得随意透传覆盖。提交类型只把可能省略字段设为可选，确定提交字段保留原约束；动态配置无法静态推断时诚实降级，嵌套路径不能用浅层 Partial 冒充完整契约。编辑模型不等于接口 DTO。

## 6. 未保存内容与重置

当前业务值与初始化快照有差异，或控件仍保留未完成／非法输入时，均触发可能丢失编辑内容的关闭确认。恢复原值且没有临时编辑内容后不再提醒；纯显示格式、焦点、弹层展开不算业务修改。库原始 isDirty 不直接替代此规则。

会丢弃未保存业务值或控件未完成输入的 reset，同样经过统一丢弃保护；取消时保留当前内容，提交期间禁止执行。获准后恢复本次快照，清临时输入和错误，更新修改状态，不重新请求服务器，不触发用户级联。普通缓存标签切换不销毁内容时无需确认，搜索草稿不自动算业务编辑。浏览器刷新／关闭的原生离开保护不承诺强制拦截或自定义文案。

## 7. 异步选项与联动

| 接入能力 | 当前契约 |
| --- | --- |
| 静态选项 | 直接提供数组 |
| optionsSource | 资源侧查询配置工厂，接收类型化依赖／关键词，公共控件创建 Vue Query observer；工厂本身不调用 composable |
| 默认单条对象 | label／value／可选 disabled；表单只存 ID／ID 数组 |
| 原始对象 | getOptionLabel／getOptionValue／isOptionDisabled 访问器，渲染可访问原对象；精确签名待验证 |
| 全量／分页 | 显式区分；默认支持数组与已解包 records／total，特殊响应显式 getOptions |
| 分页参数 | 复用 infinite Query 的 initialPageParam／pageParam／getNextPageParam，资源定义下一页，公共层不猜业务协议 |
| 页面自持 Query | 保留为特殊组合，不能与公共 observer 建立两份可写状态源 |

查询键由资源侧拥有，覆盖上级、关键词及身份等标识结果集的条件；无限查询的逐页加载进度由 pageParam 管理，不混入结果集查询键。共享候选缓存只读，不因一个控件关闭而误取消其他使用者。候选查询共同受容器／字段可用、首次展开、依赖就绪及资源条件约束，预加载或业务配置不能绕过隐藏／业务禁用／只读规则；按 ID 名称补查与整组候选查询分别判断。加载期间的临时不可操作不等于业务禁用，不据此剔除提交字段。

- 默认首次展开加载，可按字段提前加载；完整小集合本地筛选，大集合显式远程搜索。远程默认防抖 300 毫秒，可覆盖；中文组合输入未完成不提前查询，依赖变化或释放后取消过时调度。
- 分批候选点击“加载更多”，不默认无限滚动；协调追加／刷新，追加失败保留当前候选，重复点击不重复发起。
- 最终失败只弹一次，关闭重开允许重试；失败不等于空结果或值失效，不显示其他查询候选，也不因任意选项失败统一阻止整表提交。
- 已有名称优先使用记录／页面提供的 ID＋名称，其次候选缓存，再按显式配置按 ID 补查。补查失败不清值；缺少全部来源时明确暴露配置缺口。
- 原值只有被完整允许集合或服务端明确判为失效，才保留并标不可用，由用户依字段规则处理；当前搜索／分页没找到不是失效证据。

联动由被影响字段声明 dependencies 与清值策略。依赖声明本身不清值，clearOnDependencyChange 默认关闭，明确开启后仅用户实际修改及合法级联清值；初始化／回填／reset 不误清。多依赖可声明清值触发子集。按控件空值契约清理，先达到一致状态再查询；候选查询、名称补查与候选可用条件分别表达。自动改值链显式单向且禁止循环，普通读取或相互校验不等于改值循环。

## 8. Slots 与自定义控件

默认只替换输入区域，公共层保留标题、说明、错误和布局；完整字段替换作为显式扩展。插槽、render 和局部自定义组件共用类型化协议：当前值、受控更新入口、失焦通知、有效禁用／只读／提交锁定、错误关联标识、焦点注册，以及必要的未完成编辑状态。

自定义控件不得创建第二份已选业务值，不得绕过字段旧错误清理、联动来源和交互锁定。特殊字段不要求加入全局注册平台。精确插槽名称、上下文属性、焦点与编辑草稿注册签名待验证；本次不发明接口拼写。

## 9. Methods 与只读状态

| 方法 | 语义 |
| --- | --- |
| validate() | 校验参与字段及适用跨字段规则；不保存、不关闭，默认不抢焦点 |
| submit() | 复用默认保存流程，可等待；区分成功、校验失败、保存失败、结果未知、未执行 |
| reset() | 恢复本次初始化快照与编辑状态；提交期间不可执行 |
| focusField(name) | 类型化字段路径；不可聚焦时明确未完成，不强改字段状态 |
| requestClose() | 编辑容器专有，复用提交锁定及未保存保护，获准才更新 open |

表单公开只读 isDirty／isSubmitting；编辑容器另有 isLoading／isReady。默认操作区、插槽与 ref 共用同一入口。未挂载／未就绪／关闭时不能伪装执行成功，重复调用不重复写。没有默认绕过保护的 close、任意 setValues 或完整引擎可变对象；必要原生能力从明确扩展入口接入。

## 10. 待验证与验收

待定义完整泛型、深字段路径、条件省略推导、动态配置降级、跨字段参与与错误优先级、必填标记来源、输出转换契约、服务端字段错误及未知路径兜底、插槽和方法返回类型、初始化代次／取消协议。不得以示意接口宣称这些已解决。

原型验收须覆盖合法与负向类型样例、九类控件清空／0／false／日期往返、隐藏与只读提交差异、非法中间输入关闭保护、初始化和用户级联区别、过时选项响应、保存失败／未知／成功后的刷新失败、关闭快速重开、自定义控件锁定／错误关联／聚焦，以及默认按钮与 ref／插槽共用行为。
